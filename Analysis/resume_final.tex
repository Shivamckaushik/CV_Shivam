\subsection{2. Wafer Defect Detection \& Classification (WM-811K)}
{\small \href{https://github.com/Shivamckaushik/Visual-inspection-for-Wafer-Defect-Detection-Classification-WM-811K-.git}{GitHub}}
\begin{itemize}[leftmargin=*, nosep, topsep=3pt]
    \item Built an end-to-end deep learning pipeline for wafer defect pattern classification on the WM-811K dataset (811K+ wafer maps, 9 defect classes) using ResNet18 and EfficientNet-B0, with a ConvAutoEncoder for anomaly detection on unseen patterns. Achieved 97.83\% overall test accuracy and 91.95\% defect-class accuracy on a severely class-imbalanced dataset (103,201 normal vs 104 Near-Full samples). Improved Scratch F1 from 0.48 $\rightarrow$ 0.820 by moving from 64$\times$64 to 128$\times$128 resolution, adding FocalLoss($\gamma$=2) and synthetic scratch augmentation; diagnosed critical training bugs across normalization, BatchNorm domain shift, loss double-suppression, and \texttt{torch.compile} checkpoint corruption.
    \item Trained a two-stage classifier (binary Stage 1 $\rightarrow$ 8-class Stage 2) for comparison: Stage 1 achieved 98.45\% binary accuracy but error propagation reduced combined accuracy to 96.74\%, confirming single-stage as the correct production model. Applied 8-view Test-Time Augmentation (+0.33\% overall, stabilises low-support classes) and built a v2+v3 ensemble classifier with per-class confidence thresholding and human-review routing for safety-critical predictions.
    \item \projectstack{PyTorch, torchvision, scikit-learn, FastAPI}
\end{itemize}

\subsection{8. SemiKG: Semiconductor Research Knowledge Graph with LLM-Powered Cypher Reasoning}
{\small \href{https://github.com/Shivamckaushik/SemiKG}{GitHub}}
\begin{itemize}[leftmargin=*, nosep, topsep=3pt]
    \item Constructed a \textbf{semiconductor research knowledge graph} by ingesting 3,200+ papers from the \textbf{Semantic Scholar API} (queries: wafer defect detection, IC failure analysis, semiconductor inspection)---extracting structured entities (Defect Type, Material, Detection Method, Dataset, Equipment, Metric) and typed relationships (\texttt{DETECTS}, \texttt{USES\_DATASET}, \texttt{ACHIEVES\_ACCURACY}, \texttt{IMPROVES\_ON}, \texttt{CITES}) via \textbf{LLM structured-output extraction} (Claude API, JSON schema-constrained), yielding a \textbf{Neo4j} graph of 24,000+ nodes and 61,000+ relationships.
    \item Designed a 5-entity domain ontology grounded in semiconductor CV literature; automated entity resolution (fuzzy deduplication + embedding similarity) reduced duplicate nodes by 34\%, ensuring graph coherence at scale.
    \item Developed a \textbf{LangGraph agent with Cypher tool-use}: natural-language queries are schema-aware---the agent generates, validates, and executes Cypher against Neo4j, then synthesises grounded answers---enabling multi-hop questions such as ``Which detection methods achieve $>$95\% accuracy on WM-811K and what backbone architectures do they use?'' without hallucination.
    \item \textbf{Benchmarked} against flat-RAG (Qdrant) on 80 domain Q\&A pairs: KG agent achieved \textbf{+28\% answer correctness} on multi-hop questions and \textbf{zero hallucinated citations} vs.\ 11\% for flat-RAG; Cypher generation accuracy 89\% on held-out query set.
    \item \projectstack{Neo4j, Cypher, Semantic Scholar API, Claude API, LangGraph, LangChain, spaCy, FastAPI, Streamlit, Docker}
\end{itemize}

\subsection{9. SemiAgent Hub: MCP Server + A2A Orchestrated Multi-Agent System for Semiconductor Intelligence}
{\small \href{https://github.com/Shivamckaushik/SemiAgent-Hub}{GitHub}}
\begin{itemize}[leftmargin=*, nosep, topsep=3pt]
    \item Built a \textbf{Model Context Protocol (MCP) server} exposing 7 semiconductor domain tools (Neo4j Cypher query, Qdrant semantic search, SECS/GEM alarm lookup, DINOv2 defect classifier, process parameter retrieval, SemiFA report trigger, wafer map annotator)---making the entire semiconductor intelligence stack accessible to any MCP-compatible client (Claude Desktop, Cursor, custom agents) via a single standardised interface.
    \item Architected four \textbf{Agent-to-Agent (A2A)} protocol agents---each publishing an \texttt{AgentCard} declaring capabilities, input/output schemas, and skills per the A2A spec: \textit{Defect Analyst} (image + telemetry intake), \textit{Root Cause Reasoner} (KG causal traversal), \textit{Process Optimizer} (parameter recommendation), and \textit{Report Composer} (structured output)---enabling dynamic agent discovery and task delegation without hardcoded orchestration logic.
    \item Demonstrated \textbf{cross-agent delegation}: Defect Analyst receives a wafer image, classifies it via MCP DINOv2 tool, then posts a structured A2A task to Root Cause Reasoner; the Reasoner queries the Neo4j KG via MCP Cypher tool and returns a causal chain; Process Optimizer receives the chain and responds with Bayesian-optimized parameter corrections---full pipeline completing in under 12 seconds end-to-end.
    \item MCP server and all four A2A agents containerised and orchestrated with \textbf{Docker Compose}; verified MCP compatibility with Claude Desktop; A2A task routing tested with Google's \texttt{a2a-sdk} reference client.
    \item \projectstack{MCP Python SDK, A2A SDK (Google), LangGraph, Neo4j, Qdrant, DINOv2, Claude API, FastAPI, Docker Compose}
\end{itemize}
