\subsection{2. Wafer Defect Detection \& Classification (WM-811K)}
{\small \href{https://github.com/Shivamckaushik/Visual-inspection-for-Wafer-Defect-Detection-Classification-WM-811K-.git}{GitHub}}
\begin{itemize}[leftmargin=*, nosep, topsep=3pt]
    \item Built an end-to-end deep learning pipeline for wafer defect pattern classification on the WM-811K dataset (811K+ wafer maps, 9 defect classes) using ResNet18 and EfficientNet-B0, with a ConvAutoEncoder for anomaly detection on unseen patterns. Achieved 97.83\% overall test accuracy and 91.95\% defect-class accuracy on a severely class-imbalanced dataset (103,201 normal vs 104 Near-Full samples). Improved Scratch F1 from 0.48 $\rightarrow$ 0.820 by moving from 64$\times$64 to 128$\times$128 resolution, adding FocalLoss($\gamma$=2) and synthetic scratch augmentation; diagnosed critical training bugs across normalization, BatchNorm domain shift, loss double-suppression, and \texttt{torch.compile} checkpoint corruption.
    \item Trained a two-stage classifier (binary Stage 1 $\rightarrow$ 8-class Stage 2) for comparison: Stage 1 achieved 98.45\% binary accuracy but error propagation reduced combined accuracy to 96.74\%, confirming single-stage as the correct production model. Applied 8-view Test-Time Augmentation (+0.33\% overall, stabilises low-support classes) and built a v2+v3 ensemble classifier with per-class confidence thresholding and human-review routing for safety-critical predictions.
    \item \projectstack{PyTorch, torchvision, scikit-learn, FastAPI}
\end{itemize}
